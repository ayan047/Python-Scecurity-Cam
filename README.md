# Python-Scecurity-Cam
The main moto of this project was to make any spare webcam or a laptop as a security camera. When any unwanted movement takes place in front of the camera the user will be notified with a alarm sound . The user can set the size of the object that he/she want to be aware of, such as human/ dogs/cats.

Technology Used: 

Python Programming language
Python opencv module


Responsibilities: 
Making the spare cameras as a security device.
Making sure that the users will be aware of any unwanted movement takes place.
Cheapest security program .
